# Hospital Bed Optimization Dashboard

## Overview
Developed a Power BI dashboard to analyze hospital bed occupancy, patient wait times, department efficiency, and treatment costs to support operational decision-making.

## Tools Used
- Power BI
- DAX

## Key KPIs
- Bed Occupancy Rate
- Average Wait Time
- Total Patients
- Average Treatment Cost

## Key Insights
- Emergency department operated near full occupancy.
- Neurology showed higher wait times despite lower occupancy.
- Patient admissions fluctuated across months.
